# rules

Prints the writing rules an agent reads before drafting: the principles behind the shape, what is different about an agent's own repo, the closed set of sections and their order, the kill list of headings that never earn their place, what CONTRIBUTING and docs hold, and the specs the check accepts beside an SVG. The same text ends with the shipped table of every rule id, its default level and what a good README has, listed in full on [the rule ids reference](rule-ids.md).

## Arguments

None.

## Flags

None. Output is always the same plain markdown text.

## Exit codes

0 always.

## Output formats

Plain markdown text, printed to standard output. There is no `--format` flag.

## Example

```
readmerlin rules
```
