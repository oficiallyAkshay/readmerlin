# Docs

These pages are for the agent that writes or checks a README with readmerlin, and for a contributor who wants the command and rule reference in full.

- [Write a README](guides/write-a-readme.md): the order of work an agent follows with the skill, from gathering context to a clean pages check.
- [Keep it true](guides/keep-it-true.md): how the action and the CI workflow hold the three pages to their rules on every merge.
- [check](reference/check.md): what the check command reads, its flags, its exit codes and its output formats.
- [context](reference/context.md): what the context command gathers from a repo before an agent drafts anything.
- [rules](reference/rules.md): what the rules command prints.
- [init-workflow](reference/init-workflow.md): what the init-workflow command writes.
- [Rule ids](reference/rule-ids.md): the full table of the 57 rules, their levels and what a good README has.
- [Settings](reference/settings.md): every key readmerlin.json accepts, with its default.
- [Hero spec](reference/hero-spec.md): the three hero layouts, the fields each one takes, and how the drift test holds an SVG to its spec.
- [Changelog](changelog.md): what shipped in each version.
