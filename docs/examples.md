# Examples

## tidy-inbox

[examples/tidy-inbox](../examples/tidy-inbox/README.md) is a small agent skill, written to readmerlin's own shape, that turns a work trip's scattered receipts into one expense claim. Its README shows the fan hero layout drawing two sources, inbox and calendar, feeding six kinds of receipt into one claim, and its In action section links to [a real claim the skill built](../examples/tidy-inbox/examples/claim.md) for a June client trip. Read it as a worked instance of every part the shape asks for: a hero drawn from a spec, features stated as outcomes, a Fit section with no install step since the skill needs no separate login, and a Security and limits section whose checklist matches what the skill actually never does.
